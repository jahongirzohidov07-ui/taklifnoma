Bir martalik sozlash (2 daqiqa)
  1. Shu havolani oching — GitHub'ga kirgan bo'lishingiz kerak
  2. Token name: taklifnoma · Expiration: 1 year
  3. Repository access → Only select repositories → taklifnoma
  4. Permissions → Contents → Read and write
  5. Pastdagi Generate token → chiqqan kodni nusxalab, shu yerga qo'ying

Kalit faqat shu qurilmada saqlanadi va hech kimga yuborilmaydi. U faqat «taklifnoma» omboriga fayl yozishga ruxsat beradi. Telefon yo'qolsa — GitHub'da kalitni o'chirib qo'ying.
